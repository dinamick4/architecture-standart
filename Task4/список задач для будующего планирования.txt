
Список задач для каждой системы для будущего планирования:

1.  Интернет-Банк

 - изменение архитектуры для добавления логики BFF
 - доработка и улучшение API для работы с АБС
 - улучшение производительности системы для обработки большого числа запросов
 - Улучшение системы мониторинга по стабильности и производительности
 
2. Автоматизированная банковская система (АБС)

 - Доработка регулярного экспорта актуальных ставок по депозитам для кол-центров и партнёров.
 - Улучшение производительности АБС для снижения времени отклика при высоких нагрузках.
 - подключение дополнительных сторнних сервисов для получения дополнительной важной информации для улиентов по депозитам
 
3. Кол-центр

 - Разработка/доработка функционала по быстрому доступу менеджеров к актуальным ставкам по депозитам. 
 - Автоматизация рутинных операций для повышения производительности сотрудников.
